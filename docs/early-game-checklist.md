# 序盤チェックリスト (LLM 用の目安 — スクリプトではない)

スポーン直後〜最初の拠点まで、流れは会話と LLM の判断に任せる。
このリストは「次に何が要るか」の確認用で、順番の強制はしない。
確認は get_state の所持品で行う。

## フェーズ 1: 木と道具
- 原木を 4 個以上 (木を掘る)
- 作業台を作って置く
- 木のツルハシと斧 (craft)

## フェーズ 2: 石器と食料
- 丸石を集めて石のツルハシ・斧・剣
- かまど (丸石 8)
- 食料を 3 個以上: 狩りは fight の targets 指定
  (例 minecraft:cow / minecraft:sheep — 羊毛も兼ねる)、
  倒した後は自動でドロップを拾う

## フェーズ 3: 仮拠点
- 場所を決めたら waypoint に home を記録
- 整地: clear_area (窪地は fill=true、材料は土→丸石の順で自動)
- 小屋: schematic_create で単純な形を設計 → build_prepare →
  build_schematic。建てた後に light_up で明かり
- チェストを置いて logistics で預け入れ

## フェーズ 4: 寝床
- 羊毛 3 → ベッドを作って置く (フェーズ 2 の羊と兼用)
- 夜は SleepTask で越す。ベッドが無いうちは無理に夜を戦わない

## フェーズ 5: 鉄と洞窟へ
- cave_assist / branch_mine で鉄を集める
- 鉄のツルハシとバケツが揃ったら序盤卒業の目安

## 判断の置き所
- 夜が近い・HP が低い時は、チェックリストより安全を優先する
  (ReflexPolicy が最終ライン)。
- プレイヤーが一緒にいる時は、同伴プロファイル (D35/D36) の
  声かけと分担を優先する。このリストは段取りの補助に留める。

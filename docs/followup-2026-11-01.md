## 実装したもの

### P2 — セッション終了時の自動要約
- `Journal.sessionSummary(record)`: 前回要約以降の episodes/goals を機械集計
  （件数・成功/失敗・action別・目標完了/進行中・1行サマリ）。
- `Journal.endSession()`: 要約を episode + JSONL に記録してから flush。
  bridge の SIGINT/SIGTERM ハンドラから呼ぶ。
- MCP ツール `session_summary`（record=true でマーカーを進める）。

### P3 — atomic snapshot + stale lease 回収 / suffix repair
- `RunHold` に永続化を追加（`data/run-state.json`、tmp→rename の atomic write）。
  holds / lastRunAt / lastError / running を状態変化のたびに保存。
- 起動時に `running=true` のまま残っていたら stale とみなして回収:
  running を落とし、`staleRecovered` を立て、external hold で止める。
  `loop_status` で観測可能。runner は `runStateFile` を渡す。
- suffix repair: `Journal.failedWorks()` が失敗した work について
  完了済み checkpoint とエラーを返す。MCP ツール `work_resume_plan` と、
  runner プロンプトの「前回失敗した作業」セクション（完了済み step を
  再実行せず失敗箇所から組み直す指示）で LLM に渡す。

### P4 — クエスト set-aside
- `QuestGraph` に失敗カウント + 棚上げ集合を追加し、`data/quest-aside.json`
  に永続化。失敗 3 回で自動的に `frontier()` から外れる。
- `goal_set` で quest 目標（`quest:<id> <title>`）が failed で終わると
  自動で失敗カウントに連動する。完了検出時はカウントをリセット。
- MCP ツール `quest_aside`（list / aside / unaside / fail）。
  `quest_plan` の出力に aside / failures を併記。

### P5 — 技能 7 本（skills/）
- `farm`: 成熟作物（obs.block_state の age 判定）を収穫して植え直す。
  小麦/にんじん/じゃがいも/ビートルート/ネザーウォート。
- `locate`: /locate 構造物・バイオーム。結果をチャットログから読む。
- `pet_care`: オオカミ/ネコ/ウマ等の好物（ホットバー内）をあげる。
- `logistics`: チェストへ預け入れ/取り出し。container.read の
  container_idx でプレイヤー側とチェスト側を区別。
- `fishing`: 浮きの沈み込みでアタリ検知、釣果はインベントリ差分で数える。
- `build_schematic`: .litematic/.schem を y 下から順に実建築。
  既設ブロックはスキップする冪等方式（中断しても続きから再開可能）。
- `fly_elytra`: 高所から滑空 + 花火加速で目標へ。MVP（障害物回避なし、
  落差 8 未満では離陸しない）。
- 基盤追加: SkillCtx に `chatLog()` と `schematicPlan()` を追加。

### P6 — 承認 UI（Web）と複数 bot 管理の土台
- 承認 UI: `GET /approvals`（簡易ページ）+ `GET/POST /api/approvals`
  （Bearer 認証は /mcp と同じ）。pending の確認と approve/deny が可能。
- 複数 bot: `BotManager`（bridge/src/bots.ts）。primary は従来どおり。

  ツールで状態を見る。追加 bot 宛のコマンドルーティング
